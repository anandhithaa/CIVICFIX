## CIVICFIX

CivicFix is a full-stack civic complaint management platform that allows citizens to submit and track municipal complaints while enabling administrators to monitor and manage them through a dedicated dashboard.

**Features**
- User registration and JWT-based login
- Role-based access for users and administrators
- Submit and track civic complaints
- Rule-based complaint classification
- Automatic category and priority assignment
- Suggested civic department
- Admin dashboard for monitoring complaints
- Complaint filtering and status updates

## Tech Stack

**Frontend**
- React
- Vite
- Axios

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
